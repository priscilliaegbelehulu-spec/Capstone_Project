# Employee Productivity & Workplace Well-Being Analysis Dashboard
## 📌 Project Overview

This dashboard analyzes employee productivity, work arrangements, work-life balance, and mental well-being across different regions and workplace models (Remote, Hybrid, and Onsite). The goal is to uncover patterns affecting employee productivity and identify actionable strategies that organizations can implement to improve workforce performance, satisfaction, and overall well-being.

The dashboard focuses on:

Employee productivity trends
Work-hour patterns
Work-life balance
Social isolation
Stress and mental health indicators
Company support systems
Workplace arrangement effectiveness
